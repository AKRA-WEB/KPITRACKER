# Worker Sprite Assets

Put imported Baker Mart employee sprites in this folder.

Keep the original exports in this folder. The app imports the processed transparent files from `clean/` using these filenames:

- `male-smile.png`
- `male-neutral.png`
- `male-pout.png`
- `male-cry.png`
- `male-dead.png`
- `female-smile.png`
- `female-neutral.png`
- `female-pout.png`
- `female-cry.png`
- `female-dead.png`

Use pixel-art exports with transparent backgrounds. If the source export still has a checkerboard background, regenerate the matching file in `clean/` before deploying.
